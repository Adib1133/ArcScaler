A FEW THINGS TO KNOW

Before you begin.

Does this enable XeSS in every game?

No. Game inputs, graphics APIs and runtime compatibility determine what is possible. Detection provides evidence; the game's overlay is needed to verify activation.

Can I go back to my original files?

ArcScaler keeps original-file backups. Restore removes files it created and restores the originals. Externally changed files require conflict handling. Undo last change retains one previous deployment after an update.

Where are my profiles stored?

Profiles, downloaded releases, cached icons and logs are stored locally in %LOCALAPPDATA%\ArcScaler. Diagnostic reports redact personal paths by default and are not uploaded automatically.

How do I get the app or build it?

Visit GitHub Releases for published downloads. Developers can install requirements.txt and run main.py. An offline executable build additionally requires the validated runtime package described in the repository README.
